# 🗃️ Featured Projects
- 🍀 [Clover Image Tiny](https://github.com/neonforestmist/Clover-Image-Tiny)
  - Compact 512×512 Stable Diffusion 1.4-class model family built for local and on-device image generation.
  - Supports Diffusers, a local Gradio interface, CLI generation, and private Core ML inference on iPhone.
  - Expanded into a full ecosystem with a dedicated inpainting model, named LoRA styles, a visual LoRA trainer, a hosted Hugging Face demo, and a native SwiftUI iOS app for on-device Core ML generation.
  - Published with reproducible releases, documented provenance, pinned dependencies, automated CI checks, and platform-specific companion projects.

- ✍️ [SmolGPT-Fables](https://github.com/neonforestmist/SmolGPT-Fables)
  - 1.71B-parameter creative-writing model adapted from SmolLM2 for generating structured one-to-six-scene fables.
  - Released in BF16, compact GGUF, and INT4 Core ML variants for desktop, llama.cpp, and native Apple workflows.
  - Includes a hosted Fable Studio, an on-device iOS implementation, and a custom story-training dataset.
  - Evaluated with dedicated story-behavior tests covering scene counts, character-name retention, story structure, and Core ML numerical validation.
